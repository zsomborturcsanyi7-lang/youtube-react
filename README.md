# YouTube 2.0 — React+TypeScript+Vite videó platform (mock adatokkal)

**Status:** ⚠️ Prototype — React UI kész, mock videó adatok, nincs backend

React+TypeScript+Vite alapú videó platform UI. Tartalmaz videó lejátszót (react-player), YouTube Shorts-stílusú görgethető felületet, sidebar navigációt és mock videó adatokat. **Nincs backend — csak frontend prototípus.**
