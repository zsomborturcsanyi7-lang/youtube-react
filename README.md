# youtube-react

React and TypeScript video platform interface built with Vite and modern component architectures.

## Overview & Purpose
youtube-react is a front-end web application prototype designed to explore video streaming UI layouts, responsive component design, and media player state management. It provides a clean, YouTube-inspired interface for browsing and viewing video content.

## Key Features
- Responsive video player integration supporting multiple media formats and sources.
- Component-driven architecture using reusable UI elements.
- Fast development reload and build bundling via Vite.
- Type-safe front-end logic written entirely in TypeScript.

## Tech Stack & Dependencies
- **Core Framework**: React 18
- **Language**: TypeScript
- **Build Tool**: Vite
- **Media Player**: react-player
- **Styling**: Tailwind CSS / CSS Modules
- **Icons**: Lucide React

## Installation & Setup

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn package manager

### Steps
```bash
# Clone repository
git clone https://github.com/zsomborturcsanyi7-lang/youtube-react.git
cd youtube-react

# Install dependencies
npm install

# Start local development server
npm run dev
```

## Usage Examples
To build the application for production deployment:
```bash
npm run build
npm run preview
```
